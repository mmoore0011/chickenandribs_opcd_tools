# chickenandribs OPCD Tools

A collection of Unity and Blender tools for building golf courses with
[OPCD](https://zerosandonesgcd.com/) (Open Platform Course Design) for
GSPro.

See [LICENSE.md](LICENSE.md) for usage terms and
[CONTRIBUTING.md](CONTRIBUTING.md) for branch/release conventions.

## Tools on this branch

| Tool | Description |
|---|---|
| [`meshgapdetector`](meshgapdetector/README.md) | Blender addon that finds and fixes gaps between meshes |
| [`moving_vehicles`](moving_vehicles/README.md) | Procedural low-poly background traffic for Unity |
| [`SkyDome`](SkyDome/README.md) | Animated inside-out sky dome with script-free cloud drift |

More tools are in active development on the `dev` branch and get
promoted here as they're ready for general use.
